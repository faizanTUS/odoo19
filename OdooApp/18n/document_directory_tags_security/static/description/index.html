1. User Access Configuration

After activating the module, navigate to Settings > Users & Companies > Users and select the user to whom you want to grant the appropriate access rights.

2. Menu Visibility After Configuration

Once the configuration is completed, the corresponding menu will appear on the home dashboard, as shown in the attached screenshot. This indicates that the module has been successfully configured and the assigned access rights are applied correctly.

3. Accessing the Directories Menu

Upon clicking the newly available menu, you will be able to view all the directories listed under the Directories section, as illustrated in the attached screenshot. This provides a centralized view for managing and organizing document directories.

4. Creating Directory Tags

Navigate to the Configuration menu and open the Directory tab. From here, you can create new tags to organize your directories effectively.
For example, you can create tags such as Sales, Purchase, and Marketing, and assign distinct colors to each tag for better visual identification and management.

5. Creating Document Tags

In the Configuration menu, navigate to the Document Tags section. Here, you can create new tags to categorize documents based on their status or purpose.
For instance, you can create tags such as Draft and Confirmed, and assign specific colors to each tag for improved visual distinction and easier document management.

6. Creating a New Directory

To create a new directory, navigate to the Directories section and click on Create.
For example, you can create a directory named HR Documents. After that, configure the necessary details such as Parent Directory, Sequence, Company, Related Model, Sequence Prefix, and Sequence Padding as per your requirements.
In the Notebook section, you can select the Directory Tags that were created earlier to properly categorize and organize the directory.

7. Configuring Directory-Level Security

Within the Notebook section, navigate to the Security tab. Here, you can assign specific User Groups and individual Users to control access.

8. Managing Sub-Directories

There is also a Sub-Directories tab available within the directory form. From this section, you can create and manage sub-directories under the currently opened directory.
This allows you to build a hierarchical structure, making it easier to organize documents within parent and child directories.

9. Viewing Directory Structure

Navigate to the Directory Structure menu from the menu bar to get a complete overview of all directories along with their respective sub-directories.
This view presents a hierarchical structure, allowing you to easily understand the relationship between parent and child directories and manage them more efficiently.

10. Accessing All Documents

Additionally, a menu named All Documents is available in the menu bar. This section provides a comprehensive view of all documents across the entire module.
It allows users to easily browse, search, and manage documents from a single centralized location, regardless of their respective directories.

11. Accessing My Documents

A My Documents menu is also available in the menu bar. This section displays all documents associated with the currently logged-in user across the entire module.
It provides a personalized view, allowing users to quickly access and manage their own documents from a single place.

12. Directory Access Based on User Permissions

In the directory form view, open a specific directory—for example, Parent. Within the Security tab, assign a user such as Demo to this directory.
With this configuration, the selected user will have access only to this particular directory, ensuring that they can view and interact exclusively with the directories assigned to them.

13. Verifying User-Specific Directory Access

Navigate to Settings > Users & Companies > Users and select the user you want to configure as a document user. For example, choose the Demo user and assign the appropriate document-related access rights.
After completing the configuration, log in with the same user. The user will then be able to view only those directories that have been explicitly assigned to them, ensuring proper access control and data security.

14. User-Specific Documents in My Documents

Within the My Documents menu, users can view all documents that have been uploaded or attached by them.
This ensures a personalized workspace where each user can easily access and manage only their own documents, improving efficiency and maintaining proper data segregation.

15. Understanding Document Access Rights

Assign document access rights to a specific user-for example, John Wick-based on your security configuration.
Once these permissions are applied, the user will only be able to view and manage their own documents, as per the defined access rules.
This demonstrates how the access control system ensures data security by restricting visibility and actions according to user-specific permissions.

What is the purpose of the Document Directory Hub module?

This module helps you organize, manage, and control access to documents using a structured directory system with advanced security and tagging features.

How do I access the module after installation?

Once installed and configured, the module menu will appear on the home dashboard based on your access rights.

Can I create sub-directories?

Yes, you can create sub-directories from the Sub-Directories tab within any directory form.

What are Directory Tags and Documents Tags?

Directory Tags are used to categorize directories (e.g., Sales, Purchase, Marketing) and Document Tags help classify documents based on their status or type (e.g., Draft, Confirmed). and both can be color-coded for easy identification.

Does this module support multiple users working simultaneously?

Yes, multiple users can work in the system with proper access controls in place.
