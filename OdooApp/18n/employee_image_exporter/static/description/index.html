Advanced Employee Image Exporter

The Advanced Employee Image Exporter module enhances Odoo's Employee Management by providing a flexible tool to export employee images with advanced customization. Users can export images for all employees, selected employees, or domain-filtered records, with an option to include archived employees.

It supports dynamic file naming patterns (name, identification number, record ID, or custom formats), multiple output formats (Original, JPEG, PNG), and optional image resizing. All images are packaged into a clean ZIP file for easy use in HR documentation, ID cards, audits, or backups.

The module also includes access-controlled export logs, allowing only assigned users to view export history and track who performed each image export operation.

1. Activate the module.

Install the Advanced Employee Image Exporter module

2. Configuring Access Rights for Image Export

After installing the module, you need to configure user permissions.

Navigate to Settings > Users & Companies > Users, select the desired user (e.g., Mitchell Admin), and assign the appropriate Human Resource access rights that allow downloading employee images as a ZIP file. Save the changes to apply the permissions.

3. Accessing the Employee Image Export Menu

Next, navigate to the Employees module. You will now see the new Export Employee Images menu available, indicating that the module has been successfully activated and permissions are correctly configured.

4. Exporting Images from the Employee List View

In the Employees list view, select the employees whose images you want to export. Then open the Actions menu, where you will find the option "Export Images as ZIP". Simply click this action to proceed with the export process.

5. Using the Export Wizard

After clicking Export Images as ZIP, a wizard will appear as shown in the reference image. Since we already selected multiple employee records in the list view, choose "Selected Records" as the export option. Then configure the wizard by setting the Naming Mode to Employee Name, selecting Main Image as the image field, and choosing Keep Original for the output format. After applying these settings, click Generate ZIP. The system will process the request, and your ZIP file containing the selected employee images will be ready for download,So download that ZIP.

6.Download Confirmation

After the ZIP file is downloaded, you can open it to verify that all selected employee images have been exported successfully according to the configuration you specified in the wizard.

7. Exporting Images Using Domain Filter

Next, we use the Domain Filter option to export images for employees belonging to specific departments. In the wizard, configure the domain so that the employee's department is either Management or Research & Development. Set the Naming Mode to Identification Number, choose Small as the image size, and select PNG as the output format. After applying these settings, simply click Generate ZIP to download the exported images based on the defined domain criteria.

8.Verifying Domain-Based Export Output

As shown in the reference image, the exported ZIP file reflects the exact configuration selected in the wizard. The employee images are filtered according to the specified domain, named using the identification number, resized to the small image size, and saved in PNG format-confirming that the export was generated successfully following the chosen settings.

9. Exporting All Employees with Archived Records

In this step, we choose to export all employees, including archived records. For the Naming Mode, select Custom Pattern and configure it as: name-id-work_email This pattern ensures that each exported image file includes the employee's name, ID, and work email in the filename. Next, set the Image Size to Very Small and choose JPEG as the output format. After configuring these options, proceed to generate and download the ZIP file containing all employee images according to the custom pattern.

10.Verifying the Custom Pattern Export Output

As shown in the reference image, the exported ZIP file matches the configuration applied in the wizard. All employee images—including archived records-are exported using the custom filename pattern (name-id-work_email), resized to the Very Small size, and saved in JPEG format. This confirms that the export has been generated accurately based on the selected settings.

11. Granting Access to Export Logs

Now, we assign the necessary access rights so that Mitchell Admin can view the Employee Image Export Logs. After enabling these permissions, the user can see all export history, including settings used, timestamps, and who performed each export.

12.Viewing Export Logs

Now, under the Export Logs menu in the Employees module, you can see detailed records such as the export date and time, the user who performed the export, and other relevant information. This completes the workflow and demonstrates how the module functions end-to-end.

What does the Advanced Employee Image Exporter module do?

It allows users to export employee images in bulk with customizable options such as filters, file naming patterns, image formats, resizing, and ZIP packaging.

Can I export only selected employees?

Yes, you can export all employees, only selected employees, or employees filtered using a custom domain.

Does the module support archived employees?

Yes, you can choose whether to include or exclude archived employees during export.

Can I customize the file name for each exported image?

Yes, you can use dynamic naming patterns such as employee name, identification number, record ID, or create your own custom pattern using fields like name, email, etc.

Can users see the export history?

Yes, the module includes access-controlled export logs. Only assigned or authorized users can view these logs.

Is the module useful for HR activities?

Yes, it is perfect for HR documentation, ID card preparation, auditing, record keeping, and backups.
