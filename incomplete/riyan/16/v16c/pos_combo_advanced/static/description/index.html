Advanced POS Combo & Bundle Products

The Advanced POS Combo & Bundle Products module enables businesses to sell combo and bundled products directly from the Point of Sale in a simple and controlled way. It allows you to define combo products that require the cashier to select specific items from predefined groups, ensuring accuracy, consistency, and faster order processing.

When a combo product is added to the POS cart, the system automatically opens a selection popup where the user must choose the required items (such as drinks, sides, or add-ons). These selections are stored with the order line and clearly displayed on the POS receipt.

What is a combo product in POS?

A combo product is a single POS item that includes multiple selectable products grouped together, such as a meal deal or product bundle. When the combo product is added to the cart, the user must select items from predefined groups.

Can I control which products are allowed in a combo?

Yes. You can define combo groups and specify exactly which products can be selected in each group. These groups can be reused across multiple combo products.

Can I set minimum and maximum quantities for combo items?

Yes. The module allows you to configure minimum, maximum, and default quantities at both the combo group level and the individual combo item level.

Can combo items be displayed in list or grid view?

Yes. Combo items can be displayed in List or Grid view, and the default display mode can be configured from the POS settings.

Are combo item quantities editable in POS?

Yes. Cashiers can adjust the quantity of each combo item within the allowed limits defined in the configuration.

Will the selected combo items appear on the POS receipt?

Yes. Selected combo items are clearly displayed under the main combo product on the POS receipt.
