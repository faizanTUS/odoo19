Exporting Repair Order Reports with ZIP Password Protection

This feature streamlines the process of managing and exporting Repair Order reports by enabling the generation of a password-protected ZIP file containing multiple documents. Whether dealing with numerous repair orders, this tool simplifies file management by efficiently gathering all QWeb-generated reports into one compressed, secure package. Users can choose to create either password-protected or unprotected ZIP files, providing flexibility in safeguarding sensitive information.

1. To Configuration Repair Orders follow below steps.
  • Go to "Settings."
  • Navigate to the "User" section.
  • Scroll down until you see a new field labeled "Export Repair Order".
  • Activate or enable this field.
  • After enabling, refresh the page.
  • Once enabled, a button will be visible in Repair Orders tree view.
  • The button will also be available in the Repair Orders server actions.
2. Enabling the Wizard Button in Repair Orders Views
  • Go to "Repairs" module.
  • Navigate to the "Orders" section.
  • Once enabled:
    • An "Export Repair Orders" button will appear when you select records in the Repair Orders tree view.
    • This functionality is also accessible via server actions in the Repair Orders menu.
3. Exporting Repair Orders as ZIP Files with Optional Password Protection
  • Select records in the Repair Orders tree view.
  • Click the "Export Repair Orders" button.
  • A wizard will open, displaying the selected records.
  • In the wizard, you will find the "Export Repair Orders" button.
  • You can choose to create either a password-protected or unprotected ZIP file based on your requirements:
    • For a password-protected ZIP: Enter a ZIP password.
    • For an unprotected ZIP: Leave the ZIP Password fields empty.
4. Generating and Extracting Password-Protected Repair Orders ZIP Files
  • Click the "Export Repair Orders Zip" button.
  • Enter a ZIP password to generate a password-protected Repair Orders ZIP file.
  • Refer to the image for a visual representation.
  • When you extract the file, you will need to enter the ZIP password to open it.
** Viewing Password-Protected Repair Orders PDF **
  • When you unzip the file:
    • You will need to enter the ZIP password to open it.
    • This will allow you to view the POS Sessions (Sales Details) PDF.

Can I export multiple Repair Order reports at once?

Yes, the feature allows you to batch export multiple Repair Order reports into a single ZIP file.

How do I add a password to the ZIP file?

During the export process, you will be prompted to enter a password for the ZIP file. If no password is entered, the file will be unprotected.

What happens if I forget the ZIP file password?

If you forget the password, there is no way to recover it through the system. You will need to repeat the export process and set a new password.

Is the password protection optional?

Yes, adding a password is optional. If you prefer not to use one, simply leave the password field blank.

What format are the Repair Order reports exported in?

The reports are generated in PDF format and then compressed into a ZIP file for easy storage and transfer.

Is there a limit to how many reports I can export at once?

There is no specific limit, but exporting a large number of reports may take additional time depending on your system's performance.
