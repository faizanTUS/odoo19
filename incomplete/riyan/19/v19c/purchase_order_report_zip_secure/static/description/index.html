Exporting Purchase Orders Reports with ZIP Password Protection

This feature allows you to easily export and download Purchase Orders (including both purchase orders and requests for quotations) as a single, password-protected ZIP file. It simplifies the process by gathering all the required QWeb-generated documents into one secure, compressed file, which can be protected with a password for easy access and storage.

1. To Configuration Purchase Order follow below steps.
  • Go to "Settings."
  • Navigate to the "User" section.
  • Scroll down until you see a new field labeled "Export Purchase Order".
  • Activate or enable this field.
  • After enabling, refresh the page.
  • Once enabled, a button will be visible in Requests for Quotation and Purchase Orders tree view.
  • The button will also be available in the Requests for Quotation and Purchase Orders server actions.
2. Enabling the Wizard Button in Purchase Order and Requests for Quotation Views
  • For Purchase Quotation:
  • Once enabled:
    • Go to "Purchase" module.
    • Navigate to the "Orders" section.
    • Select "Requests for Quotation" in the drop-down menu of Orders
    • An "Export Purchase Quotation" button will appear when you select records in the Requests for Quotation tree view.
    • This functionality is also accessible via server actions in the Requests for Quotation menu.
  • Similarly For Purchase Orders:
    • Go to "Purchase" module.
    • Navigate to the "Orders" section.
    • Select "Purchase Orders" in the drop-down menu of Orders
    • An "Export Purchase Order" button will appear when you select records in the Purchase Orders tree view.
    • This functionality is also accessible via server actions in the Purchase Orders menu.
  • You can refer to the image for a visual representation.
3. Exporting Purchase Quotations as ZIP Files with Optional Password Protection
  • Select records in the Requests for Quotation tree view or action.
  • Click the "Export Purchase Quotation" button.
  • A wizard will open, displaying the selected records.
  • In the wizard, you’ll find the following buttons:
    • "Export Purchase Quotation Zip"
    • "Export All Purchase Order/Quotation Zip"
  • You will also find options to enter a ZIP password:
    • For a password-protected ZIP: Fill in the ZIP Password fields.
    • For an unprotected ZIP: Leave the ZIP Password fields empty
4. Generating and Extracting Password-Protected Purchase Quotation ZIP Files
  • For "Purchase Quotation Zip":
    • Click the "Export Purchase Quotation Zip" button.
    • Enter a ZIP password to generate a password-protected ZIP file.
    • The ZIP file will contain both quotations and sent quotations.
    • Refer to the image for a visual representation.
    • To access the contents when you extract the file, you will need to enter the ZIP password.
  • For "Export All Purchase Order/Quotation Zip":
    • Click the "Export All Purchase Order/Quotation Zip" button.
    • Enter a ZIP password to generate a password-protected ZIP file.
    • The ZIP file will contain all Sale Order records, including:
      • RFQ
      • RFQ Sent
      • Purchase Orders
      • Canceled Orders
    • Refer to the image for a visual representation.
    • To access the contents when you extract the file, you will need to enter the ZIP password.
5. Accessing Password-Protected ZIP Files for Purchase Documents
  • For Purchase Quotation ZIP file:
  • When you unzip the Purchase Quotation ZIP file:
    • You will need to enter the ZIP password to open it.
    • This will allow you to view the Purchase Quotation PDF.
  • Similarly For All Purchase Order/Quotation ZIP file:
  • When you unzip the file containing "RFQ," "RFQ Sent," "Purchase Orders," and "Canceled Orders.":
    • You will be prompted to enter the ZIP password to open it.
    • This will allow you to view the respective PDFs for all included records.
6. Exporting Purchase Order as ZIP Files with Optional Password Protection
  • Select records in the Purchase Orders tree view.
  • Click the "Export Purchase Order" button.
  • A wizard will open, displaying the selected records.
  • In the wizard, you’ll find:
    • "Export Purchase Order Zip" button
    • Options to enter a ZIP password
  • You can choose to create either a:
    • Password-protected ZIP file by filling in the ZIP Password fields
    • Unprotected ZIP file by leaving the ZIP Password fields empty
7. Generating and Extracting Password-Protected Purchase Order ZIP Files
  • Click the "Export Purchase Order Zip" button.
  • Enter a ZIP password to generate a password-protected Purchase Order ZIP file.
  • Refer to the image for a visual representation.
  • When you extract the file, you will need to enter the ZIP password to open it.
** Viewing Password-Protected Purchase Order PDF **
  • When you unzip the file:
    • You will need to enter the ZIP password to open it.
    • This will allow you to view the Purchase Order PDF.

What is the purpose of the "Export Purchase Orders with ZIP Password Protection" feature?

This feature allows you to export and download Purchase Orders and RFQs in a single ZIP file, with the option to add password protection for enhanced security.

Can I export both Purchase Orders and RFQs at the same time?

Yes, the feature allows you to export both Purchase Orders and Requests for Quotations together into a single ZIP file.

Is the ZIP password mandatory?

No, setting a password is optional. You can choose to leave the password field blank if you don't want protection.

What happens if I forget the ZIP password?

If you forget the password, you won't be able to open the ZIP file. It’s recommended to store the password securely.

Can I extract individual documents from the ZIP file?

Yes, once you enter the password (if set), you can extract individual documents from the ZIP file.

Is this functionality available for other reports in Odoo?

Yes, this feature can be extended to other reports, such as Sales Orders, Invoices, and more.

Can I select specific reports to export or do I have to export everything?

You can select the specific reports (Purchase Orders or RFQs) you wish to export before generating the ZIP file.

How do I access a password-protected ZIP file?

When extracting the ZIP file, you'll be prompted to enter the password you set during the export process. Without the correct password, the contents of the file will remain inaccessible.

How do I export QWeb reports without a password?

To export QWeb reports without a password, select the reports you wish to include, open the export wizard, and simply skip the step where you set a password. Then, click the export button to generate the unprotected ZIP file.

What are the risks of not using a password for the ZIP file?

Without a password, the ZIP file is less secure, and anyone who has access to the file can view the reports it contains. This may not be suitable for sensitive or confidential information.

Is it possible to choose between password-protected and unprotected ZIP files for different exports?

Yes, you can choose to create either password-protected or unprotected ZIP files based on your needs for each export. Simply select or skip the password option as needed during the export process.
