Bulk QWeb PDF Download | Password Protected ZIP Export | Multi-Document Report Manager

Bulk QWeb PDF Download streamlines document management by allowing users to export multiple QWeb reports into a single password-protected ZIP archive. Instead of downloading business documents individually, users can select multiple records and generate a compressed ZIP file containing all corresponding PDF reports, making report management faster and more organized.
The module supports bulk PDF exports across multiple Odoo applications, including Sales, Purchase, Accounting, Inventory, and Manufacturing. Users can generate ZIP archives for Sales Orders, Quotations, Purchase Orders, Purchase Quotations, Customer Invoices, Vendor Bills, Credit Notes, Customer Payments, Delivery Orders, Manufacturing Orders, and Work Orders directly from their respective list views.
To enhance document security, the module provides optional password protection for generated ZIP files. This ensures confidential business documents remain secure during storage, transfer, and sharing with customers, suppliers, auditors, or internal teams.

Fully integrated with Odoo's QWeb reporting framework, the module improves productivity, simplifies bulk report downloads, and provides a centralized solution for securely exporting multiple business documents in a single operation.

To Configuration Sale Order and Quotation follow below steps.

  • Go to "Settings."
  • Navigate to the "User" section.
  • Scroll down until you see a new field labeled "Export Quotation/Sale Order".
  • Activate or enable this field.
  • After enabling, refresh the page.
  • Once enabled, a button will be visible in Sale Order and Quotation tree view.
  • The button will also be available in the Sale Order and Quotation server actions.

Enabling the Wizard Button in Sale Order and Quotation Views

  • For Sale Quotations:
  • Once enabled:
    • Go to "Sales" module.
    • Navigate to the "Orders" section.
    • Select "Quotations" in the drop-down menu of Orders
    • An "Export Sale Quotation" button will appear when you select records in the Quotation tree view.
    • This functionality is also accessible via server actions in the Quotation menu.
  • Similarly For Sale Orders:
    • Go to "Sales" module.
    • Navigate to the "Orders" section.
    • Select "Orders" in the drop-down menu of Orders
    • An "Export Sale Order" button will appear when you select records in the Sale Order tree view.
    • This functionality is also accessible via server actions in the Sale Order menu.
  • You can refer to the image for a visual representation.

Exporting Sale Quotations as ZIP Files with Optional Password Protection

  • Select records in the Quotation tree view or action.
  • Click the "Export Sale Quotation" button.
  • A wizard will open, displaying the selected records.
  • In the wizard, you’ll find the following buttons:
    • "Export Sale Quotation Zip"
    • "Export All Sale Order/Quotation Zip"
  • You will also find options to enter a ZIP password:
    • For a password-protected ZIP: Fill in the ZIP Password fields.
    • For an unprotected ZIP: Leave the ZIP Password fields empty

Generating and Extracting Password-Protected Sale Quotation ZIP Files

  • For "Sale Quotation Zip":
    • Click the "Sale Quotation Zip" button.
    • Enter a ZIP password to generate a password-protected ZIP file.
    • The ZIP file will contain both quotations and sent quotations.
    • Refer to the image for a visual representation.
    • To access the contents when you extract the file, you will need to enter the ZIP password.
  • For "Export All Sale Order/Quotation Zip":
    • Click the "Export All Sale Order/Quotation Zip" button.
    • Enter a ZIP password to generate a password-protected ZIP file.
    • The ZIP file will contain all Sale Order records, including:
      • Quotations
      • Sent Quotations
      • Sale Orders
      • Canceled Orders
    • Refer to the image for a visual representation.
    • To access the contents when you extract the file, you will need to enter the ZIP password.

Accessing Password-Protected ZIP Files for Sale Documents

  • For Sale Quotation ZIP file:
  • When you unzip the Sale Quotation ZIP file:
    • You will need to enter the ZIP password to open it.
    • This will allow you to view the Sale Quotation PDF.
  • Similarly For All Sale Order/Quotation ZIP file:
  • When you unzip the file containing Quotations, Sent Quotations, Sale Orders, and Canceled Orders:
    • You will be prompted to enter the ZIP password to open it.
    • This will allow you to view the respective PDFs for all included records.

Exporting Sale Order as ZIP Files with Optional Password Protection

  • Select records in the Sale Order tree view.
  • Click the "Export Sale Order" button.
  • A wizard will open, displaying the selected records.
  • In the wizard, you’ll find:
    • "Export Sale Order Zip" button
    • Options to enter a ZIP password
  • You can choose to create either a:
    • Password-protected ZIP file by filling in the ZIP Password fields
    • Unprotected ZIP file by leaving the ZIP Password fields empty

Generating and Extracting Password-Protected Sale Order ZIP Files

  • Click the "Sale Order Zip" button.
  • Enter a ZIP password to generate a password-protected Sale Order ZIP file.
  • Refer to the image for a visual representation.
  • When you extract the file, you will need to enter the ZIP password to open it.
** Viewing Password-Protected Sale Order PDF **
  • When you unzip the file:
    • You will need to enter the ZIP password to open it.
    • This will allow you to view the Sale Order PDF.

Exporting Receipts and Deliveries Filter Applied with Optional ZIP Password Protection

  • For Receipts (Incoming):
    • Click on "Receipts (Incoming)" to automatically apply a filter showing only incoming receipts records.
    • Removing this filter will display both receipts (incoming) and deliveries (outgoing) records.
    • If you select records in the Receipts tree view while the receipts filter is applied:
      • Click the "Export Receipts/Deliveries" button.
      • A wizard will open, displaying only the selected incoming receipts records.
      • You will have the option to "Export Receipts (Incoming) Zip".
      • You can choose to create either a password-protected or unprotected ZIP file:
        • For a password-protected ZIP: Enter a ZIP password.
        • For an unprotected ZIP: Leave the ZIP Password fields blank.
  • Similarly For Deliveries (Outgoing):
    • Click on "Deliveries (Outgoing)" to automatically apply a filter showing only outgoing deliveries records.
    • Removing this filter will display both deliveries (outgoing) and receipts (incoming) records.
    • If you select records in the Deliveries tree view while the deliveries filter is applied:
      • Click the "Export Receipts/Deliveries" button.
      • A wizard will open, displaying only the selected outgoing deliveries records.
      • You will have the option to "Export Deliveries (Outgoing) Zip".
      • You can choose to create either a password-protected or unprotected ZIP file:
        • For a password-protected ZIP: Enter a ZIP password.
        • For an unprotected ZIP: Leave the ZIP Password fields blank.
