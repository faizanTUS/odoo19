Markup Pricelist Range | Cost-Based Pricing Rules with Markup Automation

Markup Pricelist Range enhances Odoo’s standard pricelist functionality by allowing businesses to create advanced formula-based pricing rules using product cost ranges.

With this module, users can define pricing rules based on minimum cost, maximum cost, and markup percentage. When the pricing computation is set to Based on Cost Price, the module dynamically displays additional fields such as Minimum Cost, Maximum Cost, Markup Percentage, rounding options, and extra fees. This enables businesses to apply accurate, automated, and flexible cost-driven pricing strategies.

The module is ideal for companies that want to manage product pricing based on purchase cost, landed cost, supplier cost, or internal cost while maintaining consistent margins. Instead of manually calculating selling prices, businesses can automate markup rules and apply different pricing logic for different cost ranges.

This helps avoid pricing anomalies, improves pricing accuracy, supports tiered markup logic, and gives businesses better control over profitability.

What does this module do?

This module enables cost-range-based pricelist rules with automatic markup price calculation in Odoo.

Can I set different markup percentages for different cost ranges?

Yes, you can create multiple cost slabs and assign different markup percentages for each range.

How is the selling price calculated?

The selling price is automatically calculated using product cost, markup percentage, rounding, and extra fees.

Will pricing rules apply automatically in sales orders?

Yes, Odoo automatically applies the correct pricing rule during quotations and sales order creation.

Can I apply rules to specific products or categories?

Yes, pricing rules can be configured for products, product variants, and product categories.
