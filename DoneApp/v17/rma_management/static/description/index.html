RMA Management | Customer & Supplier Return Management

RMA Management | Customer & Supplier Return Management simplifies the entire Return Merchandise Authorization (RMA) process in Odoo by providing a centralized system to manage customer returns, supplier returns, product replacements, refunds, and inventory movements. The module helps businesses streamline return operations while maintaining complete traceability from return request to final resolution.

Customers can submit return requests directly from the portal for eligible sales orders, while internal users can efficiently manage approvals, rejections, replacements, refunds, and supplier return workflows. The module automatically integrates with Sales, Purchase, Inventory, Accounting, and the Customer Portal to ensure accurate stock movements, financial adjustments, and transparent communication throughout the return process.

The solution supports configurable return reasons, product return types, restocking fees, automatic stock pickings, credit note generation, supplier return management, detailed reports, and complete RMA tracking, making it ideal for businesses that require an organized and professional return management system.

Configure RMA Manager Access

After installing the module, navigate to Settings > Users & Companies > Users and open the user to whom you want to grant RMA Manager access. Assign the appropriate manager access rights and save the changes. In this example, Mitchell Admin has been granted the RMA Manager role.


Configure Return Reasons

Once the RMA Manager access has been assigned, a new RMA menu will appear in the main menu. Open the RMA module, where you will find various menus for managing the return process.
To begin the configuration, navigate to Configuration > Reasons and click Reasons to create and manage the return reasons that will be used when processing RMA requests.


Manage RMA Reasons

The RMA Reasons menu comes with several predefined return reasons, each configured with a corresponding Action and Service Charge. These default configurations can be modified to match your business requirements, or you can create additional reasons as needed.


Configure Restocking Fees

Navigate to Configuration > Restocking Fees to configure the restocking charges applied to returned products. You can define the fee using either a Percentage or a Fixed Amount, depending on your business requirements. Adjust the configuration as needed to match your return policy.


Configure RMA Product Types

Navigate to Configuration > RMA Product Types to manage the product types used during the RMA process. The module includes several predefined product types by default, as shown in the attached image. You can use these default types or modify them and create new ones to suit your business requirements.


Configure Email Templates

Navigate to Configuration > Email Templates to manage the email notifications sent during the RMA process. The module comes with predefined email templates for various RMA stages, including RMA Submitted, RMA Approved, RMA Rejected, and RMA Closed. You can customize these templates to match your business requirements and communication style.


RMA Configuration per Product

Under Inventory > Products > Products, select any product and you can now configure RMA settings for individual products directly within the Inventory tab. At the bottom of the tab, users can define the RMA Product Type, set the RMA Return Quantity Threshold, and select a Default RMA Reason for the current product. This feature enables businesses to establish product-specific return policies, ensuring greater control, automation, and consistency in the RMA process.


Create a Customer RMA

To create a new customer RMA, navigate to Customer RMA and click New. First, select the relevant Sales Order (for example, S00034). Once selected, the Customer and Applied Date are populated automatically.
Next, assign a Responsible Person and set the Priority if required. Then, choose the product to be returned. Only the products available on the selected sales order can be selected. Enter the Return Quantity, select the appropriate Return Reason, and the corresponding Action will be filled in automatically based on the selected reason. The Unit Price is also populated automatically from the sales order.
After verifying all the details, click Save and then Submit to create the Customer RMA record.


Approve the Customer RMA

Once the Customer RMA has been created, click Approve to process the request. After approval, the RMA status changes to Approved.
Since the selected return reason is Replacement, only the Unit Price is displayed in the order line, while the Refund Amount remains empty because the request is not processed as a refund.
After approval, additional smart buttons become available in the header, including Return Picking and Replacement, allowing you to access the related inventory transfer and replacement records directly.
You can also verify in the Chatter that the RMA Submitted and RMA Approved email notifications have been sent successfully.


View Return Picking

After the Customer RMA is approved, two smart buttons are available in the header. Click the Return Picking smart button to view the inventory transfer created for the RMA. This opens the related stock picking record, where you can review all the return movement details associated with the Customer RMA, as shown in the attached image.


View Replacement Order

Click the Replacement smart button in the Customer RMA form to open the related Sales Order created for the replacement process. This displays the replacement sales order associated with the Customer RMA, allowing you to review and manage the replacement details, as shown in the attached image.


Process the Customer RMA

Once the replacement and return picking have been reviewed, click the Processing button in the header. The Customer RMA status will change to Processing, indicating that the return request is currently being processed, as shown in the attached image.


Close the Customer RMA

After completing the return process, click the Close button in the header to finalize the Customer RMA. The RMA status changes to Closed, indicating that the return request has been successfully completed.
You can also verify in the Chatter that the RMA Closed email notification has been sent successfully to the customer, as shown in the attached image.


Apply a Reason to All RMA Lines

When creating a Customer RMA with multiple products, you can use the Bulk Apply Reason to All RMA Lines option to simplify the process. Select a return reason, such as Damaged or Defective Items, and the selected reason will be automatically applied to all RMA lines.
Based on the applied reason, the corresponding Action and Amount are also populated automatically for each RMA line, eliminating the need to configure them individually and ensuring consistent return processing.


View the Journal Entry

After the Customer RMA has been processed through the required stages (such as Submitted and Approved), the module automatically creates the corresponding Journal Entry. You can open the generated journal entry to review the accounting impact of the RMA. As shown in the attached image, the journal entry is linked to the Customer RMA, ensuring complete financial traceability.


Print RMA Reports

The module allows you to print RMA Reports in both bulk and individual formats. From the Customer RMA list view, select multiple RMA records and download their reports in a single action. Alternatively, you can open any individual Customer RMA record and print its report directly from the form view.
As shown in the attached image, the RMA reports are generated successfully with all the relevant return details.


View the RMA Dashboard

Navigate to the RMA Dashboard to gain a comprehensive overview of all RMA records. The dashboard displays return requests grouped by their current status using multiple chart views, providing clear insights into the distribution of RMAs across different stages of the workflow, as shown in the attached image.


Access Customer Returns from the Portal

From the Customer Portal, you can see a new My Returns menu. This menu allows customers to access and manage their RMA requests directly from the portal, providing a convenient way to view return records and track their status.


View Your Return Requests

Click the My Returns menu to view all Customer RMA requests associated with the currently logged-in customer. Only the return records belonging to that customer are displayed, ensuring secure access and allowing users to easily track the status of their own return requests.


Customer Portal RMA Creation

Customers can easily create return requests directly from the customer portal. This self-service feature enables users to initiate RMAs online, track return status in real-time, and upload necessary documents, enhancing customer experience while reducing support workload.


View Customer RMA Details

Click on any RMA record in the My Returns list to open its detailed view. Here, customers can view all the information related to the selected RMA, including the return details, products, quantities, return reason, status, dates, and other relevant information, as shown in the attached image.


User Access Restrictions

When a user is assigned RMA User access instead of RMA Manager, the Configuration menu is not available. As shown in the attached image, users with standard access can perform their assigned RMA operations, while configuration options remain accessible only to users with RMA Manager rights.


Create a Supplier RMA

To create a Supplier RMA, navigate to Supplier RMA and click New. The creation process is similar to the Customer RMA workflow. Select the relevant purchase details, enter the required return information, choose the appropriate return reason and action, and save the record.
As shown in the attached image, the Supplier RMA is created successfully with all the necessary details.
