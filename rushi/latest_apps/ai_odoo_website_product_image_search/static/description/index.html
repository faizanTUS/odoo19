    Setup & Configuration

    Install Odoo AI Odoo Website Product Image Search Module
    1. From App Menu > Install Module

    2. Module Configuration

    Navigate to Website → Configuration → Settings and enable “Product Image Search on Website” to activate the image search icon in the shop’s search bar.

    3. Configure Product Image Search Settings

    Navigate to Website → Configuration → Website Product Image Search to configure the product image search settings.

    4. Configure Products and Search Accuracy

    After navigating to Website → Configuration → Website Product Image Search, You can go to the products section and either select all products or manually add specific products. In the Result Accuracy section, you can apply filtering to image search by selecting Low, Standard, High, or Exact accuracy levels.

    5. Image Search Popup Functionality

    Click the image icon in the shop’s search bar to open a popup. → You can drag and drop or upload an image. → then click the Search button to find matching products based on the uploaded image.

    6. Image-Based Search Result

    The image you added in the popup will be used to perform a search and display matching products based on that image.

    How does the image search work in this module?

    When a user uploads an image on the website shop, the module uses AI-powered visual recognition to compare the uploaded image with existing product images in the database. It then returns the closest visual matches, helping users find similar products quickly and easily.

    What type of product images give the best results?

    High-quality, clear product images with a clean background give the most accurate results. Ensure your product gallery is well-organized with proper lighting and minimal distractions for better AI matching.

    Do I need any external service or API key for this to work?

    No, the module works completely within Odoo using built-in AI logic. There is no need to subscribe to third-party APIs or services. It is self-contained and easy to set up on your Odoo server.

    Can this module be used on mobile devices?

    Yes, the module is fully responsive and optimized for mobile devices. Users can upload images directly from their phone cameras or gallery and get instant product results — just like on desktop.

    Do I need to install any Python libraries separately for this module to work?

    Yes, the following Python libraries must be installed in your environment to ensure the module functions properly:
    pip install tensorflow
    pip install Pillow
