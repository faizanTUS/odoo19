What is the AI Chatbot in Odoo?

The AI Chatbot is an intelligent virtual assistant integrated into Odoo, designed to help users quickly find answers, automate support tasks, and improve overall user experience. It uses Natural Language Processing (NLP) to understand and respond to user queries.

What database connection details are required?

To connect the chatbot to your Odoo database, you’ll need the following parameters:

  • db_host
  • db_port
  • db_user
  • db_password

How does the chatbot understand what users are asking?

It uses built-in logic or AI (if configured) to process what the user says, then matches it to the right Odoo model and fetches the data.

Can it search real-time Odoo records?

Yes. The chatbot fetches data live using Odoo’s ORM, so results are always up to date.
