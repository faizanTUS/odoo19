Universal Document Attachment Preview — PDF, Office, Video

Preview all common attachment types in Odoo 18 directly from chatter and the standard file viewer modal. Reduce unnecessary downloads, save disk space, and review Word, Excel, PowerPoint, PDF, images, video, and audio faster.

What you get

  • MS Office & spreadsheets: Word, Excel, PowerPoint, CSV, RTF, macro-enabled Office types (embedded via Microsoft Office Online or optional Google Docs viewer).
  • OpenDocument: ODT, ODS, ODP.
  • PDF, images, video, audio: Same Odoo flow as usual, with extra video/audio MIME types for broader in-browser playback.
  • Advanced Office UI: Zoom, wheel zoom, reset, and open in new tab from the preview toolbar.

Quick installation

  1. Add the module folder document_attachment_universal_preview to your addons_path.
  2. Restart Odoo, update the Apps list, install Universal Document Attachment Preview — PDF, Office, Video.
  3. Open Settings → Discuss and review the two preview options (Office Online vs Google viewer).
  4. Set web.base.url (Technical → System Parameters) to your public HTTPS URL if you use online Office/Google preview.
Privacy: Online preview sends a resolvable file URL to Microsoft or Google so the document can be rendered. Use only if this matches your security and compliance requirements.
