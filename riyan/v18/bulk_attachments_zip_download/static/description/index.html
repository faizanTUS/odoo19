Bulk Attachments ZIP Download

Productivity module for Odoo 18: select records in a list view, use Actions → Download all files, confirm in the preview wizard, and receive a single ZIP archive named {model}_attachments.zip — perfect for CRM, Sales, HR, Project, and custom apps.

Highlights

  • Mass document handling without opening each record or chatter file.
  • Preview: filename, MIME type, size; remove lines before download.
  • Optional chatter attachment inclusion.
  • Administrator limits: max files and max total size (MB).
  • Respects Odoo access rules on records and attachments.

Typical workflow

  1. Select one or more rows in any model list view.
  2. Open Actions → Download all files.
  3. Review the table → Download.
