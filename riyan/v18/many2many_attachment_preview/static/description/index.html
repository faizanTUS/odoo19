Many2Many Attachment Preview — PDF, Image, Video & Office

Preview documents before downloading them. Works on many2many_binary fields and chatter files in Odoo 18 — PDF, images, video, and optional Microsoft Office / Google Docs embedding.

Why install

  • Reduces unnecessary downloads and saves user storage.
  • One consistent full-screen viewer for form attachments and mail attachments.
  • Advanced: Office Online or Google Docs viewer, zoom toolbar, extra video formats.

Quick setup

  1. Put the addon under odoo18/project/many2many_attachment_preview/ and add .../odoo18/project to addons_path.
  2. Restart Odoo, update Apps list, install Many2Many Attachment Preview.
  3. Use widget="many2many_binary" on Many2many('ir.attachment') fields.
  4. For Office preview in production, set web.base.url to your public HTTPS URL.
