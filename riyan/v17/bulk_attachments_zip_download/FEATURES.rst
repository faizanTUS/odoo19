================================================================================
Bulk Attachments ZIP Download — feature list (Odoo App Store / SEO)
================================================================================

Short pitch
-----------
Save time on **mass document handling**: export every attachment linked to your
selected CRM leads, **sales orders**, **HR documents**, **project tasks**, or
any other model from the **list view** as one **ZIP** file.

Core features
-------------
* **Universal list views:** works on standard and custom models that use attachments.
* **Actions menu integration:** “Download all files” appears when records are selected.
* **Preview table:** filename, type (MIME), size; delete rows to exclude files from the ZIP.
* **Chatter attachments:** optional inclusion of files posted on record chatter.
* **Naming convention:** archive named ``<model>_attachments.zip`` (technical model name).
* **Duplicate-safe names:** second ``report.pdf`` becomes ``report (1).pdf`` inside the ZIP.
* **Security:** respects record and attachment access rights; download URL is tied to the wizard creator.

Advanced / administrator
------------------------
* **General settings block** “Bulk attachment ZIP”: default chatter inclusion, max files, max total MB.
* **Per-action opt-out:** set context key ``disable_bulk_attachment_zip`` on a window action to hide the menu entry on specific list views.
* **Domain selection:** supports “Select all” / domain-based selection within Odoo’s active-id limit.
