List & Kanban Auto Refresh — Soft live data reload

Odoo 17 List / Tree Kanban General Settings

Keep list (tree) and kanban views up to date with periodic soft reloads (data refresh only — no hard browser refresh). Ideal for queues, pipelines, and boards where records change often.

What you get

  • Global control — Enable or disable auto refresh and set the default interval under Settings → General Settings → Auto Refresh — List & Kanban.
  • Minimum interval 1000 ms — Protects server performance; default interval 10 000 ms.
  • Per-view toolbar — Pause or resume for the current list/kanban screen; opening another menu or a new view instance restores the global default behaviour.
  • Smarter refresh — Pauses while the tab is hidden; skips reload during list inline edit; avoids overlapping loads.

Configuration (short)

  1. Install list_kanban_auto_refresh from Apps.
  2. Open Settings → General Settings, configure Allow auto refresh data and Refresh interval (ms), then Save.
  3. Refresh the browser if you change settings so the session picks up new values.
  4. Use the Auto Refresh button on list and kanban control panels.
See CONFIGURATION.md in the module folder for a full step-by-step guide and behaviour table.
